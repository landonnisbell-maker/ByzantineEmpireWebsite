BYZANTINE EMPIRE WEBSITE — V93 UPDATE ONLY

This is a patch for the already-installed V92 website, NOT a standalone site.

WHAT CHANGED
- Removed all image outlines/borders on the Historical Connection page.
- Added a subtle, edge-aware drop shadow behind its images.
- Added user-provided product illustrations to the "Every product has a history" section:
  Paramerion Sword -> sword; Gold Jewelry -> ring; Gàros -> fish and sauce;
  Apáki -> sliced meat; Silk Textiles -> cloaked figure; Coins -> gold nomisma.
- Six new product images are optimized WebP files with transparency retained.
- Kept the existing Hidden in Plain Sight images, layout, Works Cited and scrolling.

HOW TO INSTALL
1. Open the ZIP and then the ByzantineEmpireWebsite folder inside it.
2. Copy the files and the historical-experience folder into your existing
   ByzantineEmpireWebsite repository, preserving the folder structure.
3. Choose REPLACE when prompted for files with the same names.
4. Commit and push the changed/new files.
5. Refresh your site (Ctrl+Shift+R) if your browser shows cached content.

The package intentionally contains only the files changed for V93.
The original images under historical-experience/assets from V92 must remain.
