BYZANTINE V5.8.24 — EDITABLE CONTENT FOR ALL FOUR CRYSTAL PAGES
OFFICIAL GITHUB UPDATE ONLY — APPLY AFTER V5.8.23

2. Copy index.html, _next, and all four byzantine-*-content.js files into
   the ROOT of your EXISTING GitHub repository (the directory containing index.html).

5. For later text edits, open ONLY the corresponding byzantine-*-content.js file.

landmarks, portal, favicon or navigation animation.
