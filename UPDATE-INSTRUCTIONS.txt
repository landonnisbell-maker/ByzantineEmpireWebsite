V5.8.14 — Official GitHub landmark-transition fix (after V5.8.13)

INSTALL IN EXISTING REPOSITORY
1. Extract this ZIP.
2. Copy its _next folder into your current ByzantineEmpireWebsite repository,
   replacing ONLY the matching _next/static/chunks/1502ibkr~cu.4.js.
3. Commit and Push origin in GitHub Desktop.
4. After GitHub Pages finishes deploying, hard-refresh (Ctrl+Shift+R).

FIX
- V5.8.13 used the page interiorReveal uniform to hide the landmark images
  on entry. That value switches state with the 3D scene and could create
  flickering/ghosted overlapping landmark images.
- V5.8.14 removes that coupling. Entry now uses a reverse of the already
  working 1.05-second sine.inOut exit fade, with its start delayed until
  the crystal's real inward traversal begins (1.15 seconds).
- Exit stays the same 1.05-second sine.inOut fade with 0.38s delay.
- Mountain awaken smoothing, between-crystal landmark deformation, positions,
  page text, favicon, and all other scenes remain untouched.

This ZIP contains only 1 updated website file; nothing from the standalone
team/profile experiments is included.
