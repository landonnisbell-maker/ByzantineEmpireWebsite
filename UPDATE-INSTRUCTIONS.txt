INSTALL IN YOUR EXISTING REPOSITORY ROOT
1. Extract this ZIP.
2. Copy index.html, favicon-32x32.png, favicon.ico and _next/ into
   the root of the EXISTING ByzantineEmpireWebsite GitHub repository.
3. Replace matching files, commit, and push to GitHub.
4. After deployment, open in a new browser tab and refresh with Ctrl+Shift+R.
   Favicons may be cached; a private browser window can help verify the new one.
