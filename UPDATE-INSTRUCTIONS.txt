BYZANTINE MARKET V23 — DIRECTLY REPLACES CRYSTAL 3 PAGE (UPDATE ONLY)
======================================================================
The original Market text/image page is now removed from the WebGL interior
rendering path for Crystal 3. The original three OTHER crystal pages remain.

1. EXTRACT the entire ZIP first (do not copy files from inside a ZIP preview).
2. COPY EVERY FILE/FOLDER inside the extracted ZIP to the ROOT of your
   existing ByzantineEmpireWebsite GitHub repository.
3. When File Explorer asks, REPLACE files in the destination.
4. Make sure these 4 important files are committed:
   - index.html
   - _next/static/chunks/1502ibkr~cu.4.js
   - byzantine-market-content.js
   - market-runtime/market-bridge.js
   And the market-runtime/gallery, palia and product folders remain present.
5. Commit, push and wait for GitHub Pages deployment; hard-refresh the website.
6. Open /ByzantineEmpireWebsite/market-runtime/VERIFY-DEPLOYMENT.html on the
   published site. ALL EIGHT tests should be green, not just HTTP 200.
7. Enter Crystal 3. Its original project page is suppressed at its renderer;
   the five-cloth gallery is opened by the same renderer.

WHY THIS IS DIFFERENT FROM V20-V22:
Previously we relied on watching navigation state from outside the interior
renderer. V23 changes the actual code that paints the old Market page. When
that renderer displays Crystal 3, it instead paints a blank texture and emits
an explicit activation event that the gallery consumes.

FOR DEBUGGING:
On the main site in DevTools > Console, run:
  window.__BYZ_MARKET_DEBUG__?.()
Expected while Crystal 3 is open: visible:true, state.active:true, index:2,
status:'interior'.

This is an update-only package and does not overwrite the other site assets.
The complete graphical WebGL interaction could not be verified here.
