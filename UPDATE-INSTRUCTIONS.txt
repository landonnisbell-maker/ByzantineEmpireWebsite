BYZANTINE V5.8.6 — RESTORE PORTAL TRAVERSAL ANIMATION

Official GitHub patch only. Apply after V5.8.5.

1. Extract this ZIP.
2. Copy the _next folder into the ROOT of your existing ByzantineEmpireWebsite GitHub repository.
3. Replace the matching file (01ay6y4_-9myt.js).
4. Commit, push, wait for GitHub Pages deployment, then hard-refresh your browser.

CHANGE
The existing backward-scroll restriction waited only for the routing state to
switch to projects. That state changes DURING forward portal travel, and the
restriction immediately jumped scroll to the crystal landing point.

The restriction now remains inactive until the actual forward scroll reaches
the crystal settle position. Then it activates, preventing backward scrolling
from returning through the portal. Choosing Portal in the menu still allows
the intentional backward transition.

Unchanged: GitHub Pages path and refresh behavior, portal colors, portal/crystal
shaders, original mountain animations, four projects/pages, landmark images,
menu navigation and every other website asset.
