V5.8.16 — Live landmark visibility guard
OFFICIAL GITHUB UPDATE ONLY — apply after V5.8.15

INSTALL:
1. Extract this ZIP.
2. Copy _next/static/chunks/1502ibkr~cu.4.js into the same location in
   your existing GitHub repository, replacing only this file.
3. Commit and Push origin; after Pages deployment, use Ctrl + Shift + R.

CHANGES:
- The landmark renderer now reads the currently selected crystal and its
  interior/morph state in the render loop, rather than relying on React's
  one-frame-delayed state capture.
- Outside a genuine exterior crystal-to-crystal morph, exactly one landmark
  mesh is allowed to draw. Old meshes are explicitly made invisible rather
  than just given zero opacity.
- Any interrupted image morph is stopped and its original mesh geometry
  restored at the time the renderer detects the state change.
- Existing return-from-page opacity transitions are left unchanged.

TEST:
Blue page > back > Purple crystal > enter > back > Green crystal > enter,
then repeat quickly in a different order. You should not see the image from
any previous crystal behind the current crystal while zooming into its page.

Verified: JS syntax, exclusive visibility condition over four pages and all
state combinations, no changes outside the landmark renderer, ZIP integrity.
A deployed browser WebGPU test remains necessary.
