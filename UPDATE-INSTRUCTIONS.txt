BYZANTINE V5.8.22 — ABOUT US CONTENT ONLY
OFFICIAL GITHUB UPDATE — APPLY AFTER V5.8.21

1. Extract this ZIP.
2. Copy index.html, _next/, and byzantine-about-us-content.js into the ROOT of
   your existing GitHub repository (the folder containing index.html).
3. Replace only the matching files.
4. Commit and push. Once GitHub Pages deploys, hard-refresh with Ctrl+Shift+R.

HOW TO EDIT THE TEXT LATER:
Open byzantine-about-us-content.js in a normal text editor.
Change the writing between backticks under each heading, save, commit, and push.
There is NO need to edit minified _next JavaScript or index.html again.

WHAT CHANGES:

items, because Time Frame is counted separately). All supplied wording is kept
as given. Existing image placeholders, crystal scenes, animations, and other
crystal pages remain unchanged. Section text wraps onto the site's original
