BYZANTINE V5.8.9 — PORTAL, CRYSTAL AND ABOUT RECOVERY
OFFICIAL GITHUB PATCH (UPDATE ONLY) • APPLY AFTER V5.8.8

1. Back up or commit your current repository before applying.
2. Unzip this patch. Copy its _next/ folder into the ROOT of your existing
   ByzantineEmpireWebsite repository. Replace only the FOUR matching .js files.
3. Commit and Push origin. Wait for GitHub Pages deployment.
4. On the live website, press Ctrl+Shift+R or open a fresh private window.

ROOT FIXES
1. Removes a circular JS module dependency introduced with V5.8.7:
   navigation -> crystal store -> audio -> navigation. This can disturb a
   cold first load and leave page-switching state incompletely initialized.
2. The Portal-return reset now runs in the existing experience transition
   controller AFTER the Portal menu transition, not inside the router or
   ordinary crystal navigation. It returns to Introduction/01 upon re-entry.
3. Removes the V5.8.7 About-scroll clamp. It measured a transformed Contact
   handoff element and could stop scrolling before About was fully accessible.
   The original V5.8.6 backward lock still blocks scrolling out of crystals.
4. Preserves Contact route blocking and removed navigation links, no Lite
   menu options, GitHub Pages homepage/refresh fix, and lossless landmark WebP.
