BYZANTINE MARKET V21.1 — FIX MARKET CRYSTAL ACTIVATION
======================================================
This is an UPDATE-ONLY package, NOT a complete replacement website.
It contains your current index.html, the market-runtime/ folder and .nojekyll.
It does NOT overwrite your main _next static chunk or any other crystal content.

1. Extract the ZIP.
2. Copy index.html and the market-runtime/ folder into the ROOT of the
   existing ByzantineEmpireWebsite GitHub repository, merging/replacing files.
3. Add .nojekyll at repository root if it is not already present.
4. Keep all your existing _next/, __assets__/, portal, About Us and crystal files.
5. Commit, wait for GitHub Pages to deploy, and refresh with Ctrl+Shift+R.
6. Enter the site normally, go to Crystal 3 (Market). After its original crystal
   transition, the five-cloth gallery should fade in over the original Market page.

WHY V20 FAILED:
Its bridge required the Market crystal to report an exact internal
`interiorStatus === "interior"`. This can disagree with the displayed page.
V21.1 independently checks the crystal state, the existing page title, the
visible Market heading and the route. It also derives its asset URL from
its own script path rather than hard-coding the repository prefix.

TROUBLESHOOTING:
Add ?byzmarketdebug=1 to the official site URL to log Market bridge
messages in DevTools. In the Console run:
window.__BYZ_MARKET_BRIDGE?.debug()
This will report whether the bridge sees the Market page, whether the gallery
is displayed and where its iframe was loaded from.

The five product pages, images, preloading and scroll-reset system are
unchanged from the working V19 / previous V20 package. No changes to the
main site's Enter button or original crystal animations.

The embedded gallery and product scenes are third-party captured code and
assets: make sure you have publishing/reuse rights before public deployment.
