Byzantine Empire — V140: Custom Crystal MP4 Videos

INSTALL (update-only)
1. Open the ByzantineEmpireWebsite folder in this ZIP.
2. Copy the included index.html and __assets__ folder into the root of your EXISTING GitHub repository.
3. Allow index.html to be replaced. The four NEW video assets are added to __assets__.
4. Commit/push, allow GitHub Pages to deploy, and hard refresh (Ctrl+Shift+R).

VIDEO MAPPING
Crystal 1 — Introduction: __assets__/Crystal-Introduction-V140.mp4
Crystal 2 — About Us: __assets__/Crystal-AboutUs-V140.mp4
Crystal 3 — Market: __assets__/Crystal-Market-V140.mp4
Crystal 4 — Historical Connection: __assets__/Crystal-Historical-V140.mp4

VIDEO FORMAT
Each video was converted to 720x720, H.264 MP4, 30 fps, without an audio track.
The complete original widescreen video is displayed within the square frame.
The empty space is filled with a softly blurred extension of the image, not a crop.

NOTE
This update changes video references only (in index.html) and adds four MP4 files.
It does not modify the original 3D shaders, crystal meshes, camera transitions, product pages, scrolling, or Works Cited behavior.
The old MP4s may remain in __assets__, but the website no longer references them for the four crystals.
There is no need to delete the old videos.
