BYZANTINE EMPIRE WEBSITE — GITHUB PATCH V5.8.3

This is UPDATE-ONLY for the already-existing ByzantineEmpireWebsite repository.
DO NOT delete your other website files or upload the ZIP itself.

INSTALL:
1. Extract the ZIP on your computer.
2. Copy index.html and the _next folder into the ROOT of your existing
   ByzantineEmpireWebsite repository, merging folders and overwriting
   matching files. Do not nest them inside another folder.
3. In GitHub Desktop, review changes, commit, and Push origin.
4. Allow GitHub Pages to deploy, then hard-refresh with Ctrl+Shift+R.

CHANGES:
- Restores the previously approved imperial-purple and molten-gold colors of
  the animated portal, plus the inner-shader correction.
- After reaching crystals, wheel/touch/trackpad scroll cannot go back into
  the portal. The existing Portal navbar option still navigates there.
- The menu's HOME navigation label is now PORTAL, pointing to the same scene.
- No changes to crystal morphing, four landmark images, mountain morphing,
  card names, page count, or other scene artwork.

Important: This patch modifies compiled client code from the already working
snapshot. Test navigating by scrolling and by menu in your published browser.
To undo, restore these eight file paths from your previous version.
